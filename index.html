Mi primera web de Lenguajes de marcas

Este proyecto presenta una pequeña página web con tres secciones principales: inicio, horario y formulario.

La intención es practicar el uso de HTML y CSS para crear una estructura clara, navegable y visualmente ordenada, con un diseño elegante y consistente en todas las páginas del sitio.

  • Diseño limpio y moderno.
  • Navegación entre páginas.
  • Formato responsive para distintos tamaños de pantalla.

Puedes consultar el horario o acceder al formulario desde el menú superior.
